Política de Privacidade — OpenDoctor

Última atualização: 8 de outubro de 2026

O OpenDoctor é um assistente de apoio à decisão clínica que, opcionalmente, permite conectar o calendário do profissional (Google Calendar e Microsoft Outlook) para exibir seus compromissos. Esta política descreve quais dados tratamos e como.

1. Dados que acessamos

  • Identificação: nome e e-mail da conta usada para conectar (Google/Microsoft).
  • Calendário (somente leitura): eventos do seu calendário, para exibi-los na agenda. Não criamos, editamos nem excluímos eventos.
  • Tokens de acesso: credenciais emitidas pelo provedor para manter a conexão.

Não coletamos dados de pacientes a partir do calendário além do que você mesmo visualiza na agenda.

2. Como usamos os dados

  • Exibir seus compromissos de calendário dentro do OpenDoctor.
  • Manter sua sessão conectada ao provedor escolhido.

Não vendemos seus dados e não os usamos para publicidade. Os dados de calendário não são enviados a serviços de terceiros nem usados para treinar modelos de IA.

3. Uso em conformidade com as políticas do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

4. Armazenamento e segurança

Os tokens de acesso são armazenados de forma segura no nosso banco de dados e usados apenas para acessar o calendário conforme a sua autorização. O acesso é restrito e trafega por HTTPS.

5. Retenção e exclusão

Você pode revogar a conexão a qualquer momento clicando em Desconectar no OpenDoctor, o que remove os tokens armazenados. Também é possível revogar o acesso diretamente em myaccount.google.com/permissions (Google) ou em account.microsoft.com (Microsoft).

6. Contato

Dúvidas sobre privacidade: privacidade@opendoctor.app.
